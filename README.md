# 音声課題の提出ツール（voice-submit）

学生がスマホでリンクを開き、画面の語や文を発音して録音し、聞き直してから送信する。
録音は先生の Google ドライブに WAV（16bit・モノラル・端末の標準サンプリング周波数）で保存され、提出記録はスプレッドシートに残る。
1つの仕組みで何回分の課題でも回せる。課題は「課題」シートに行を足すだけで増える。

- 学生用ページ：https://labphonlab.github.io/voice-submit/ （リポジトリ labphonlab/voice-submit）
- `index.html` … 学生が開く画面
- `config.js` … 受付先URL（空欄だとデモモード：録音はできるが送信しない）
- `gas/Code.gs` … 受付側（Google Apps Script）

## 学生側の流れ

1. `https://labphonlab.github.io/voice-submit/` を開くと、受付中の課題の一覧が出る（学期の初めにこのリンクを1回配り、ブックマークさせれば毎回同じ入口で済む）
   - 個別の課題へ直接飛ばすときは `…/voice-submit/?a=<課題ID>`
2. 学籍番号・氏名を入れ、マイクを許可（2回目からは学籍番号・氏名が入った状態で始まる）
3. 1項目ずつ録音 → 波形と再生で確認 → 録り直し可
4. 全項目の一覧で聞き直し → 「この内容で提出する」
5. 項目ごとに送信（途中で切れたら、送れていない項目だけ送り直す）→ 受付番号を表示

録音時はエコー除去・ノイズ抑制・自動音量調整を切っている（音声分析に使えるよう、加工しない音を取る）。
音割れ・音が小さすぎる・短すぎる録音には、その場で録り直しを促す表示が出る。

## 設置手順（初回だけ・個人の gmail アカウントで行う）

大学のアカウントでは「アクセスできるユーザー」に「全員」を選べないため、個人の Google アカウントで作る（2026-10-07 確認）。

1. https://sheets.new で新しいスプレッドシートを作る（例：「音声課題_受付」）
2. 「拡張機能」→「Apps Script」を開き、`gas/Code.gs` の中身を貼り付けて保存
3. 関数 `setup` を選んで「実行」→ 権限を許可する（「確認されていません」と出たら「詳細」→「移動」）
   - シート「課題」「名簿」「課題一覧」「提出状況」「受信ファイル」「提出一覧」と、ドライブのフォルダ「音声課題_提出」ができる
   - 1時間ごとに「課題一覧」「提出状況」を更新する自動実行も入る
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
5. 表示された URL（`https://script.google.com/macros/s/…/exec`）を `config.js` の `apiUrl` に入れて push する
6. スプレッドシートを開き直すと、メニューに「音声課題」が出る

`Code.gs` を直したときは「デプロイを管理」→ 既存のデプロイを編集 →「新しいバージョン」にする（URL が変わらない）。

## 毎回の課題の作り方

1. メニュー「音声課題」→「新しい課題のひな形を追加」→ 課題ID（例：`eng02`）を入れる
2. 「課題」シートの末尾に5行のひな形が入るので、（ ）の中を書き換える。項目が多ければ行を足す

| 課題ID | 課題名 | 説明 | 締切 | 項目番号 | 提示文 | 読み・補足 | 最長秒数 | 公開開始 |
|---|---|---|---|---|---|---|---|---|
| eng02 | 第2回 子音 | ふだんの速さで1回ずつ | 2026/10/21 23:59 | 1 | pea | /piː/ | 10 | 2026/10/14 9:00 |
| eng02 | | | | 2 | bee | /biː/ | 10 | |

- 課題名・説明・締切・公開開始は、その課題IDの最初の行だけ書けばよい
- **公開開始**を書いておくと、その時刻まで学生の一覧に出ない。10回分を学期の初めにまとめて仕込める（空欄ならすぐ公開）
- **締切**を過ぎると、一覧では「締切済み」になり、提出できなくなる（空欄なら無期限）
- 「課題一覧」シートに、課題ごとの学生用リンクと LINE 用リンク（`&openExternalBrowser=1` 付き。LINE の中ではなく Safari / Chrome で開く）が出る

## 提出状況の見方

- **名簿**シートに学籍番号と氏名を入れておくと、「提出状況」シートが名簿×課題の表になる（完了なら日時、途中で切れたら「不足 3/5」、締切後の未提出は「未提出」）。名簿にない学籍番号で出したものは下に「名簿外」として並ぶ（打ち間違いの発見用）
- 「課題一覧」には課題ごとの状態（公開前・受付中・締切済み）と提出者数
- この2枚は1時間ごとに自動更新。すぐ見たいときはメニュー「音声課題」→「課題一覧と提出状況を更新」
- 「提出一覧」は1回の提出につき1行、「受信ファイル」は録音1件につき1行（秒数・サンプリング周波数・ピーク値・ファイルへのリンク）

## ドライブの保存のされ方

```
音声課題_提出/
  eng01_第1回_母音/
    12345_目白太郎/
      eng01_12345_01_heed_20261007-2103.wav     ← 最新の完全な提出だけが直下に並ぶ
      eng01_12345_02_hid_20261007-2103.wav
      _以前の提出/                               ← 出し直す前の提出
      _未完了の提出/                             ← 通信が切れて全項目そろわなかった提出
  eng02_第2回_子音/
    …
```

- 課題フォルダは課題IDで、学生フォルダは学籍番号で振り分けるので、課題名や氏名の書き方が変わっても別のフォルダに分かれない（課題名を直すとフォルダ名も次の提出時に合わせて変わる）
- ファイル名は「課題ID_学籍番号_項目番号_提示文_提出日時」。1回の提出の全ファイルに同じ日時が付く
- 採点では各学生フォルダの直下だけを見ればよい。課題フォルダごと大学の保存先へ移せば、そのまま1回分の控えになる

## 運用上の注意

- 学生の声と氏名は個人情報。スプレッドシートとフォルダは他人と共有しない
- 採点が済んだら、課題フォルダを大学の保存先へ移し、個人のドライブからは消す（「受信ファイル」「提出一覧」の該当行も同様）
- 受付URLを知っていれば誰でも送れる（課題IDの照合と公開期間・サイズの確認だけしている）
- 動作確認：iPhone は Safari、Android は Chrome。アプリ内ブラウザ（LINE・Instagram 等）では警告を出す
